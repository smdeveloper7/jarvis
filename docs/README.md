# JARVIS 관리정책 안내

JARVIS는 요청을 작업으로 나누어 PM에게 맡기고, 세션이 바뀌어도 기록을 바탕으로 일을 이어 간다. 세 정책은 이 과정의 서로 다른 질문에 답한다.

| 읽을 문서 | 핵심 질문 | 기억할 개념 |
|---|---|---|
| [01. 상태·기억 관리](01_State_Memory_Management.md) | 무엇을 남겨야 일을 이어 갈 수 있는가? | 상태는 현재 사실, 인계는 다음 행동, 기억은 재사용할 지식 |
| [02. 에이전트 관리](02_Agent_Lifecycle_Management.md) | 담당 세션을 어떻게 안전하게 바꾸는가? | 역할은 유지하고 검증한 세션으로 담당을 전환 |
| [03. 업무 관리](03_Work_Lifecycle_Management.md) | 어떤 단위로 맡기고 언제 완료하는가? | 기능·개발 작업·위임의 완료를 각각 판단 |

## 문서 읽는 방법

01~03 문서는 기존 내용과 목차를 유지하며, 개념·정책·명령어·파일 형식·훅·예외를 한 문서에서 확인할 수 있다. 본문 그림은 핵심 관계와 흐름이 드러나도록 단순화했다. 구현·검증 현황은 2026-11-09 원문 기록 기준이다.

`diagrams/architecture.html`, `flow.html`, `layers.html`은 이전 상세 그림으로 보존했다.

`reference/` 는 정책이 아닌 참고 자료다. 지금은 [lanekeeper 와 JARVIS 비교](reference/lanekeeper_comparison.md) 가 있다. 세션 실행 바탕(Paseo)은 02 2절, 에이전트 사이 메시지 규약은 03 4절에 있다.
